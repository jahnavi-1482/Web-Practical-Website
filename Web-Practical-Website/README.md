# Web Practical Website

This project demonstrates the use of HTML to embed audio and video elements in a web page.

## Files Included

- **html/audio.html**: This file contains the HTML code for displaying audio and video elements. It includes:
  - An `<audio>` tag with controls to play an audio file (`audio.mp3`).
  - A `<video>` tag with controls to play a video file (`video.mp4`).

## Usage

1. Open the `audio.html` file in a web browser.
2. Use the controls provided to play the audio and video files.

## Requirements

Ensure that the audio file (`audio.mp3`) and video file (`video.mp4`) are located in the same directory as the `audio.html` file for proper functionality.
